# Bumabot
Bumabot is a chatbot meant for use on Twitch.tv, written in Python. It can read and write to a given chat channel, and it can use these features to both respond to specific commands and send automated messages on a timer.

This version of Bumabot is for demonstrative purposes only. It's been stripped of a lot of code related to things like inside jokes and personal shoutouts for people who drifted in and our of my chat. Additionally, the "Adventure" module is entirely unfinished. I never quite got it working and ended up abandoning it when I lost interest. As such, Bumabot may not work out of the box.

That said, you're free to use my work for reference in your own chat bot. To get it running, you'll need to, at a minimum, replace the redacted keys in Settings.py with actual keys retrieved from Twitch.tv. Once you've got all of that set up, simply execute Run.py from your command line.

There's also support for the Spotify API, if you want to update a text file with whatever song and artist you're currently listening to.
